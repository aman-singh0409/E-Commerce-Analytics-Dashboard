# E-Commerce Analytics Dashboard

## Project Overview
The E-Commerce Analytics Dashboard is an interactive business intelligence project developed using Power BI, MySQL, Python, and DAX. The project focuses on analyzing sales performance, customer behavior, product analytics, and customer churn to generate meaningful business insights.

The dashboard helps in monitoring KPIs, identifying top-performing products, understanding customer segmentation, and analyzing churn risk through interactive visualizations.

---

## Tools & Technologies Used
- Microsoft Power BI
- MySQL
- Python
- DAX
- CSV Dataset

---

# Dashboard Pages

## 1. Executive Dashboard
Provides a high-level overview of business performance.

### Features
- Total Revenue KPI
- Total Orders KPI
- Total Customers KPI
- Monthly Sales Trend
- Country-wise Sales Analysis
- Top Products Analysis

---

## 2. Customer Intelligence Dashboard
Focuses on customer behavior and segmentation analysis.

### Features
- Customer Segmentation
- Repeat Customer Percentage
- Revenue by Customer Segment
- Customer Distribution Analysis
- Purchase Behavior Insights

---

## 3. Churn Analysis Dashboard
Analyzes customer retention and churn patterns.

### Features
- Churn Customer KPIs
- Active vs Churned Customers
- Retention Monitoring
- High-Risk Customer Analysis
- Churn Percentage Visualization

---

## 4. Product Analytics Dashboard
Analyzes product and category performance.

### Features
- Product Revenue Analysis
- Category-wise Revenue
- Quantity vs Revenue Analysis
- Product Performance Comparison
- Geographic Sales Analysis
